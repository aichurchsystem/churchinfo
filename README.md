## 메뉴 구조 (상단 6개)

1. **교회정보팀 소개** — 팀 소개 · 주요 업무 · 이용 방법 · 문의
2. **노회안내** — 노회 소개 · 노회 일정 · 노회 소식
3. **사역안내** — 후임 사역자 찾기 · 교회 건물 매매·임대 · 농어촌 연결 · 목회자 가정 지원
4. **정보마당** — 목회 벼룩시장 · 공동구매·제휴 · 최근 등록 정보 · 정보 등록하기
5. **자료실** — 노회 서식 · 임직 자료 · 교회 행정 · 목회 자료
6. **커뮤니티** — 공지사항 · 행사 안내 · 사업 신청 · 자주 묻는 질문

## 동작하는 기능 (시안 범위)

- 분야·지역·검색어 3조건 검색과 결과 필터, 정렬, 페이지 나눔
- 분야 선택에 따라 항목이 바뀌는 등록 양식, 사진·첨부 선택, 접수번호 발급
- 관리자 데모: 승인·수정·숨김·마감 처리, 대표 문구·공지 변경 (브라우저에만 저장)
- 반응형: PC(1440) 6칸 카드, 모바일(390) 2열 카드 + 검색 우선 배치
